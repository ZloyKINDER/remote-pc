# RemotePC

Простой удалённый доступ к Windows-ПК **по прямому IP** — без аккаунтов, облака и установки клиента. На управляемом ПК запускается хост, на другом достаточно браузера.

## Возможности

- Экран в реальном времени, мышь и клавиатура.
- **H.264 NVENC** через WebCodecs: до 60 fps при низкой нагрузке на CPU.
- Резервные режимы **JPEG** и **WebP** (DXGI Desktop Duplication + OpenCV/mss).
- Системный **звук** через WASAPI loopback.
- Несколько мониторов: список, кнопка **⇄** и горячие клавиши.
- Ограничение FPS: **15 / 30 / 45 / 60** для всех кодеков.
- Качество, разрешение и масштаб меняются на лету.
- Графический интерфейс хоста: пароль, порт, настройки, журнал, запуск/остановка.
- Конфиг `remote-pc.json` с паролем, зашифрованным Windows DPAPI.
- Автозапуск с Windows, автоматический старт сервера и запуск с правами администратора.
- HTTPS/WSS с самоподписанным сертификатом, пароль не передаётся по сети.

## Требования

- Windows 10/11.
- Python 3.11+ (для Python 3.13 x64 есть готовые wheels в релизе).
- Chrome или Edge с WebCodecs для H.264.
- Для H.264: NVIDIA GPU с NVENC и `ffmpeg.exe` с `h264_nvenc`.
- Для звука: устройство вывода по умолчанию и пакет `soundcard` (ставится автоматически).

Без `ffmpeg.exe` или NVENC хост работает через JPEG/WebP.

## Быстрый старт

### Готовый архив

Скачайте [последний релиз](https://github.com/ZloyKINDER/remote-pc/releases/latest), распакуйте и запустите:

```text
start.bat
```

В архиве уже есть `ffmpeg.exe` и wheels для Python 3.13 x64. При первом запуске создаётся `.venv`.

### Из исходников

```powershell
git clone https://github.com/ZloyKINDER/remote-pc.git
cd remote-pc
start.bat
```

`start.bat` создаст `.venv` и установит зависимости. Для H.264 скачайте `ffmpeg.exe`:

```powershell
powershell -ExecutionPolicy Bypass -File tools\fetch-ffmpeg.ps1
```

Либо скачайте [FFmpeg essentials](https://www.gyan.dev/ffmpeg/builds/) вручную и положите `ffmpeg.exe` рядом с `start.bat`.

### Настройка хоста

1. Откроется окно **RemotePC**. Задайте пароль, порт и параметры.
2. Нажмите **«Сохранить»**, затем **«Запустить»**.
3. В окне появятся адреса и отпечаток сертификата.
4. Разрешите порт в брандмауэре (от администратора):
   ```text
   firewall.bat
   ```
5. Сделайте проброс в роутере:
   ```text
   внешний TCP 8765 → <локальный IP ПК>:8765
   ```

### Подключение с другого ПК

Откройте:

```text
https://<белый IP>:8765
```

Примите самоподписанный сертификат, введите пароль и нажмите на экран. Если ПК в той же сети, используйте локальный IP.

## Управление

| Действие | Как |
|---|---|
| Мышь | Движение, ЛКМ, ПКМ, СКМ, колесо |
| Клавиатура | Активное окно удалённого ПК |
| Мониторы | Список, кнопка **⇄**, `Ctrl+Alt+M` / `Ctrl+Alt+Shift+M` |
| Качество, FPS, разрешение, масштаб | Меню в верхней панели |
| Перемещение по увеличенному экрану | Кнопка «рука» |
| Звук | Кнопка динамика |
| Спецклавиши | Меню с клавиатурой (`Alt+Tab`, `Win`, `Ctrl+Alt+Del` и т.д.) |
| Полный экран | Кнопка в верхней панели |
| Отключение | Красная кнопка питания |

Верхняя панель через 3 секунды сворачивается в маленькую кнопку. Нажатие на неё возвращает панель; подведение курсора к верхнему краю панель не раскрывает.

## Настройки потока

| Настройка | Значения |
|---|---|
| Сжатие | H.264, JPEG, WebP |
| Кадры/с | 15, 30, 45, 60 |
| Качество | Авто, 60, 75, 85, 92 |
| Разрешение | 1280, 1600, 1920, 2560, нативно |
| Масштаб | Вписать, 100%, 150%, 200% |

H.264 использует битрейт 8/15/25/35 Мбит/с для качества 60/75/85/92. При смене FPS или битрейта H.264 энкодер перезапускается (1–2 секунды); JPEG/WebP применяют настройки сразу.

«Вписать» масштабирует кадр под окно в обе стороны. `100%` — один пиксель кадра на один CSS-пиксель.

## Звук

- Захватывается системный звук устройства вывода по умолчанию (WASAPI loopback).
- PCM 48 кГц, stereo, 16 бит; передача по тому же WebSocket.
- Браузер воспроизводит через Web Audio API после первого клика по странице.
- Кнопка динамика выключает и включает звук; состояние запоминается.
- Микрофон хоста не передаётся.

Если звука нет, проверьте устройство вывода по умолчанию в Windows и громкость вкладки браузера. В журнале хоста должна быть строка `audio loopback: <устройство>`.

## Конфигурация

Файл `remote-pc.json` создаётся рядом с `start.bat`:

```json
{
  "version": 1,
  "password": "dpapi:...",
  "port": 8765,
  "bind": "0.0.0.0",
  "max_width": 3840,
  "fps": 60,
  "quality": 85,
  "tls": true,
  "demo": false,
  "public_ip": "",
  "cert_dir": "",
  "start_with_windows": false,
  "autostart_server": false,
  "run_as_admin": false
}
```

Пароль хранится в зашифрованном виде (Windows DPAPI). Скопированный на другой ПК или под другого пользователя конфиг пароль не раскроет.

### Автозапуск

- **Старт с Windows** — регистрирует хост в автозагрузке Windows.
- **Автозапуск сервера** — сразу запускает сервер при старте приложения.
- **С правами администратора** — создаёт задачу Task Scheduler с `HighestAvailable`; UAC подтверждается один раз при настройке.

При включённых первых двух галочках после входа в Windows сервер запускается сам, а окно сворачивается в панель задач. Для этого Windows должен выполнить вход пользователя; экран блокировки не захватывается.

## Командная строка

```text
python -m remotepc --help
```

| Параметр | По умолчанию | Описание |
|---|---|---|
| `--gui` | — | Графический интерфейс |
| `--config` | `remote-pc.json` | Путь к конфигу |
| `--port` | `8765` | TCP-порт |
| `--bind` | `0.0.0.0` | Адрес прослушивания |
| `--password` | запрос | Пароль (мин. 6 символов) |
| `--public-ip` | — | Белый IP для сертификата |
| `--max-width` | `3840` | Предел ширины кадра |
| `--fps` | `60` | FPS: 15/30/45/60 |
| `--quality` | `85` | Стартовое качество |
| `--cert-dir` | `%LOCALAPPDATA%\RemotePC\certs` | Каталог сертификата |
| `--no-tls` | выкл. | Без HTTPS (только localhost) |
| `--demo` | выкл. | Тестовая картинка |

`start.bat` без аргументов открывает GUI, с аргументами работает как CLI:

```bat
start.bat --port 9000 --public-ip 203.0.113.10 --fps 30
```

## Безопасность

- HTTPS/WSS, самоподписанный сертификат.
- Пароль не передаётся: PBKDF2-HMAC-SHA256 (240 000 итераций) и HMAC обоих nonce.
- Один активный клиент.
- Ограничение попыток входа: 8 неудач с одного IP за 5 минут.
- CSP, запрет iframe, проверка Origin для WebSocket.
- Пароль в конфиге шифруется Windows DPAPI; сертификат лежит в `%LOCALAPPDATA%\RemotePC\certs`.

Самоподписанный сертификат защищает трафик от прослушивания, но не от подмены сервера при первом подключении. При работе в недоверенной сети сверяйте отпечаток.

## Ограничения

- Только Windows-хост; клиент — современный браузер.
- Нет передачи файлов и буфера обмена.
- Нет захвата экрана блокировки Windows и UAC secure desktop.
- Для ввода в приложения, запущенные от администратора, запускайте хост через `start-admin.bat`.
- Один активный клиент, без автоматического переподключения.
- H.264 идёт по WebSocket/TCP; для устойчивости к потерям нужен WebRTC/WebTransport.
- H.264 требует NVENC и `ffmpeg.exe`; иначе используется JPEG.
- DXGI Desktop Duplication может быть недоступен в RDP-сессии; тогда используется mss.

## Если не подключается

1. Проверьте, что хост слушает порт:
   ```powershell
   Get-NetTCPConnection -LocalPort 8765 -State Listen
   ```
2. Откройте `https://127.0.0.1:8765` на самом хосте.
3. Запустите `firewall.bat` от администратора.
4. Проверьте проброс роутера на локальный IP, а не на VPN-адрес.
5. Убедитесь, что белый IP внешний, а не CGNAT.
6. Изнутри сети публичный IP может не работать из-за отсутствия NAT loopback — проверьте через мобильный интернет.

## Структура

```text
remote-pc/
├─ start.bat                 запуск хоста (GUI без аргументов)
├─ start-admin.bat           запуск с правами администратора
├─ remote-pc-gui.pyw         автозапуск через pythonw
├─ firewall.bat              открыть TCP-порт
├─ requirements.txt
├─ tools/fetch-ffmpeg.ps1    скачать ffmpeg.exe
├─ remotepc/
│  ├─ __main__.py            CLI и запуск GUI
│  ├─ gui.py                 графический интерфейс
│  ├─ config.py              remote-pc.json, DPAPI
│  ├─ autostart.py           автозагрузка Windows
│  ├─ admin_task.py          Task Scheduler
│  ├─ server.py              aiohttp, WebSocket, сессии
│  ├─ h264.py                NVENC и Annex B
│  ├─ audio.py               WASAPI loopback
│  ├─ capture.py             DXGI/mss
│  ├─ winapi.py              DPI, SendInput
│  ├─ auth.py                PBKDF2/HMAC
│  ├─ tls.py                 сертификат
│  ├─ protocol.py            формат кадров
│  └─ web/                   браузерный клиент
└─ tests/
```

## Разработка

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m unittest discover -s tests
```

`ffmpeg.exe`, `wheels/`, `release/` и `remote-pc.json` не входят в git: это бинарные/локальные артефакты. Для сборки релиза используйте `tools/fetch-ffmpeg.ps1` и `pip download` для wheels.
